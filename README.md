# Ordenamiento por Burbuja en Java

## Descripción
Programa en Java que implementa el algoritmo de ordenamiento por burbuja para ordenar números enteros de menor a mayor.

## Requisitos
- Java JDK instalado.

## Clonar el repositorio
```bash
git clone https://github.com/TU-USUARIO/OrdenamientoBurbuja.git
cd OrdenamientoBurbuja
```

## Compilar
```bash
javac -d out src/Metodos_de_Ordenamiento/*.java
```

## Ejecutar
```bash
java -cp out Metodos_de_Ordenamiento.Mainburbuja
```

## Resultado esperado
```text
Arreglo original:
[6, 1, 5, 8, 3, 2, 7, 4]

Arreglo ordenado:
[1, 2, 3, 4, 5, 6, 7, 8]
```

## Algoritmo
El método Burbuja compara elementos adyacentes y los intercambia cuando están en orden incorrecto. Repite el proceso hasta que todos los elementos estén ordenados.
